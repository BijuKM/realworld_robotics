Autonomous Sweeper Robot

The goal: a robot that can sweep all debris from a given area into a dustpan, wherever that dustpan happens to be in the room.

The "given area" is either:

  1. The entire sweepable area of the room, or
  2. A patch identified by an automatic debris-detection scan (laser beams + OpenCV).

Debris Detection

For option 2, we need logic that can flag debris regardless of shape or size. For the purposes of this project, "debris" simply means anything sitting on the floor.

The approach: shine a laser beam across the floor from a fixed height on the robot. If the beam hits something, a bright spot appears in the webcam feed. So the detection rule is straightforward — the debris is tall enough to interrupt the beam, it's debris.

One wrinkle: laser spots overwhelm a webcam's sensor, so we'll need filters in the image pipeline for the spots to become trackable.

Dustpan Detection

The dustpan isn't going to be parked in the same spot every time, so we need to re-identify its location on every run. YOLOE handles this nicely — it can detect an object from a single reference image, no training pipeline required. It's essentially "show me a picture of a dustpan, and I'll find one in the scene."

The trade-off is detection rate: single-image prompting isn't as bulletproof as a properly trained model. In our case, though, it's good enough, so we'll go with it.

Transport

Standard ROS2 differential drive: two powered wheels and a passive caster. The drive motors need encoders

Navigation and Obstacle Avoidance

For full-room sweeping, we'll use an LD19 LiDAR alongside ROS2's SLAM_Toolbox for mapping and the Nav2 stack for path planning and obstacle avoidance.

For the debris-scanning mode (option 2), the LiDAR drops out of the navigation loop and is used purely for collision avoidance while the camera does the detection work.

Note: In debris-scanning mode (Option 2), the LiDAR is repurposed solely for obstacle avoidance. The primary debris-detection role is handled by the laser beam + OpenCV pipeline, freeing the LiDAR to focus on safe navigation.

Sweeping Mechanism

The actual sweeping — whether that's a physical brush, a small fan, an air blower, or some other contraption — has its own set of mechanical headaches. That's a separate project and, for now, out of scope.

Summary: The Autonomous Sweeper Robot combines laser-beam + OpenCV debris detection, YOLOE-based dustpan localisation, ROS2 differential-drive transport, and LD19 / SLAM_Toolbox / NAV2 navigation to sweep an arbitrary area into a dustpan at any location in the room.
